# Дизайн-аудит: «Панель инструментов» (Панель инструментов.svg)

Файл: `figma/Панель инструментов.svg` — плоский экспорт из Figma, viewBox `0 0 10222 16941` (высокий узкий холст). Весь текст — векторные path, читался только визуально через скриншоты браузера при разных уровнях `transform: scale()` (прямой просмотр при `transform:none` в этом файле не рендерился из-за превышения браузером лимита растровой поверхности ~16384px по высоте — 16941 > 16384; решение — масштаб ≤0.9).

## Summary

- **Всего кадров (frame) размером 1440×800**: 38 штук. Других responsive-размеров (mobile/tablet ~375–414px) в файле НЕ обнаружено — это чисто desktop-макет (1440 — стандартная Figma-frame ширина для веб-дизайна).
- Кадры организованы в **11 горизонтальных секций** (у каждой — серый заголовок-плашка над рядом кадров), где почти каждая секция = один инструмент левой боковой панели в разных состояниях (закрыт/tooltip/открытая панель/успех/ошибка). Заголовки секций (как подписаны в самом файле, сверху вниз): **List, Share, download, Add to favorite, timer, Add to folder, Flip the board, Regenerate, Play vs AI, Hint, Цвет фона**.
- По сути это **ОДИН экран** — рабочий стол решения шахматного пазла («тулборд»), продемонстрированный в ~36 состояниях/попапах его инструментов, плюс **один дополнительный самостоятельный экран** — библиотека пазлов «My Puzzles» (найдена внутри секции Share как контекст для демонстрации шаринга из библиотеки).
- Бренд подтверждён текстом на кадрах: домен в поле «Share» — **neuratop.com** (ссылки вида `https://neuratop.com/board/untitled...`).
- **Важная находка**: язык интерфейса **не полностью русский** — сильное смешение RU/EN: часть кнопок и системных сообщений на английском (`White to move`, `Retry`, `List Overview`, `Share`, `Private/Public`, `Favorite`, `Add to folder`, `Play vs AI`, `Hint`, `Generating AI tasks...`, `Copy`), часть — на русском («Ход белых», «Настройка таймера», «Подсказки закончились», «Добавлено в избранное»). Похоже на незавершённую локализацию мокапов.
- **Важная находка**: секция «Цвет фона» — это не просто цвет клеток доски, а **полная смена цветовой темы всего приложения** (фон страницы, панели, доска) — обнаружены минимум 3 темы: тёмная (дефолт), светло-серая и розовая, выбираемые из палитры 9 свотчей.
- Обнаружена **монетизационная механика**: у пользователя есть баланс «кредитов» (670 кредитов, значок молнии), подсказки (Hint) ограничены (3 на задачу) и после исчерпания предлагается платный докуп пакетами (5/10/безлимит подсказок за кредиты).

## Экран 1: Рабочий экран решения пазла (Тулборд) — базовое состояние

### Назначение
Основной рабочий экран продукта: пользователь решает сгенерированную ИИ шахматную позицию/пазл, видит доску, материальный перевес, может использовать набор инструментов слева (сохранить в список, скачать, поделиться, в избранное, таймер, перевернуть доску, перегенерировать, добавить в папку, играть против ИИ, подсказка) и менять цветовую тему.

### Layout
Полотно 1440×800, тёмный фон, разметка на 3 горизонтальные зоны:
- **Header** (верх, ~0–60px): слева — лого-иконка (два зелёных узла, соединённых линией — стилизованный «N»/нейросеть) + дропдаун с названием/типом задачи «Мат в 2 хода» (шеврон вниз); справа — бейдж «⚡ 670 кредитов» (пилюля) и аватар пользователя (фиолетовый круг «A») + имя «Алихан М.» с шевроном (дропдаун аккаунта).
- **Левая иконная тулбар-колонка** (узкая, ~40px, вертикально по центру экрана): 10 круглых/квадратных icon-button сверху вниз — List (документ/список), Download (стрелка вниз), Share (узлы/шеринг), Favorite (сердце), Timer (часы/секундомер), Flip (стрелки вверх-вниз), Regenerate (круговая стрелка), Add to folder (папка+), Play vs AI (робот/бокс), Hint (лампочка).
- **Центр — доска** (доминирующий блок, примерно 320×320 у в масштабе кадра, координаты A–H снизу, 1–8 слева, тёмная рамка-контейнер со скруглением). Над доской — индикатор материала «⛜♗ +11» (иконки фигур + число преимущества). Справа над доской — блок управления зумом: иконка fullscreen (⛶) + «10%  −  +».
- **Правый край экрана**: узкая стрелка-шеврон «‹» — судя по всему, свёрнутая/скрытая правая панель (в этом файле не раскрыта ни в одном кадре — вероятно engine-анализ/список ходов, не задокументирован).
- **Подвал доски**: слева-под доской повтор материального индикатора, кнопка-пилюля «White to move» (англ.), рядом переключатель (● заполненный / ○ пустой) с подписью «Ход белых» (рус. — дублирует то же значение на двух языках/стилях), справа стрелки пагинации «‹ ›» для навигации между ходами/вариантами решения.
- **Нижний левый угол**: маскот-персонаж — зелёный «слайм»-бот с двумя ножками (иконка чат-бота/AI-помощника) + отдельная круглая иконка чат-пузыря рядом.

### Элементы (дословный текст)
- «Мат в 2 хода» (заголовок-дропдаун задачи)
- «⚡ 670 кредитов»
- «Алихан М.»
- «10%» (зум доски)
- «White to move»
- «Ход белых»
- Координаты доски: A–H (файлы), 1–8 (горизонтали)
- «⛜♗ +11» — материальный перевес (белые +11 «очков»/фигур)

### Состояния
Базовое состояние показано минимум дважды с чуть отличающимся положением фигур/оверлеев в разных кадрах-повторах (одна и та же демо-позиция мат-в-2-хода используется как фон почти для ВСЕХ 38 кадров — везде одна и та же расстановка фигур, меняются только оверлеи/панели поверх неё).

### Переходы
Клик по каждой из 10 левых иконок → открывает соответствующую панель/модалку/тост (см. ниже). Клик по «Мат в 2 хода» — предположительно открывает выбор типа задачи (не раскрыт отдельным кадром). Клик по аватару — дропдаун аккаунта (не раскрыт). Иконка рядом с зумом (появляется только в секции «Цвет фона») — открывает палитру тем.

### Стиль
- Фон приложения (тёмная тема): `#0B0D17` / `#0E111F` / `#0D101C` / `#15192A` / `#151A2A` (несколько оттенков почти-чёрного тёмно-синего).
- Панели/карточки: `#22293F`, `#34364C` (тёмно-сине-фиолетовый).
- Светлые клетки доски: `#EFD9B8` (кремовый); тёмные клетки: `#B38867` (охра/коричневый) — классическая деревянная палитра, НЕ неоновая, контрастирует с неоновым UI вокруг.
- Неоновый зелёный акцент (лого, маскот, success-состояния): `#00ED8E`, доп. оттенки `#43FFC6`, `#77FF8B`, `#87EC96`, `#47C566`, `#00BD87`.
- Фиолетовый/индиго акцент (кнопки, выделенная клетка, бейджи): `#6C63FF`, `#7B61FF`, глубокий `#4C0BBC`, светлый `#9490FF`.
- Розовый/коралловый акцент (тема «Цвет фона» и badge-иконки): `#E0879C`.
- Выделенная клетка на доске (текущий/подсвеченный ход) — заливка сиреневым/лавандовым тоном поверх клетки.
- Шрифт — геометрический sans-serif, некрупный (заголовки модалок ~14–16px по пропорциям).

## Библиотека пазлов «My Puzzles» (встроенный самостоятельный экран)

Обнаружен внутри секции Share (правый кадр ряда, x≈6873) — совершенно другой экран, не тулборд, использованный как контекст для демонстрации модалки Share «из галереи».

### Назначение
Личная библиотека/архив сохранённых задач пользователя с папками и сеткой превью.

### Layout
- **Верхняя навигация** (полноширинный header, отличается от Экрана 1!): лого + 4 таба верхнего уровня: **«My Puzzles» (активный), «Progress», «My Class», «Tournaments»**; справа — тот же бейдж кредитов «670 кредитов» и аватар «Алихан М.».
- **Левый сайдбар** (шире, чем иконный тулбар Экрана 1, ~200px, текстовый): заголовок «Folders» со счётчиком «16»; секция «Private folders»: «Ход конём» (16), «Untitled» (18), «Untitled» (18), «Разные задачи на тактику» (13); секция «Public folders»: «Ход конём» (15), «Ход конём» (18), «Ход конём» (18), «Untitled» (18); внизу — «+ Create new folder».
- **Основная область**: заголовок текущей папки «Untitled», бейдж «🔒 Private» справа (зелёный), под заголовком — панель фильтров/табов (частично перекрыта модалкой: видны обрывки «Сегодня», «ФЕН», «Скач[ать]»), ниже — **сетка карточек-превью** пазлов (мини-доски с подписями вида «1/4 Тактика», «Ходят белые» и т.п., частота размеров превью 620×620 / 576×576 — это как раз повторяющиеся «квадратные» rect, замеченные при диагностике).

### Элементы поверх — модалка Share (вариант «из библиотеки», расширенная версия)
- Заголовок «Share», аватар «A» + код «sc:paocaic1550» + бейдж роли «coach»
- Переключатель «Private — Only you can access» / «Public — Anyone with the link» (выбран Private, фиолетовая рамка)
- Поле «Установите пароль для просмотра» с password-инпутом (точки) и иконкой глаза
- Поле ссылки «https://neuratop.com/board/untitled...» + зелёная кнопка «Copied!» (состояние после клика — было «Copy»)
- «Share to» — ряд иконок: telegram, комментарий/ссылка, X/twitter, facebook, email

### Состояния/переходы
Модалка Share из библиотеки функционально совпадает с модалкой Share из тулборда, но добавляет поле пароля и роль (coach) — предположительно только когда шаришь из контекста преподавателя/класса (связь с табом «My Class»).

### Стиль
Та же тёмная палитра, что и Экран 1; карточки папок — светло-фиолетовая плашка-иконка папки; бейдж «Private» — зелёный `#00ED8E`-подобный.

## Экран 1 — состояния инструментов (детально по каждой из 11 секций)

### 1. List (список/учебные материалы)
**Назначение**: не история решений, а **иерархический список уроков/правил шахмат** (обучающий контент).
**Элементы** (кадр «открыто»): панель «List Overview», строки:
1. «How to pieces Move» (выбрано, зелёная точка)
2. «The Foundations of the game» (оранжевая точка = развёрнуто) → вложенный подпункт «1.1 The Foundations o[f...]» (обрезано, зелёная точка)
3. «Special Move»
4. «Checkmate»
**Состояния**: закрыт / открыт с плоским списком / открыт с развёрнутым вложенным пунктом (аккордеон).
**Стиль**: панель `#22293F`, миниатюры досок слева от каждого пункта, активный пункт подсвечен зелёной точкой-индикатором.

### 2. Share (поделиться)
**Назначение**: получить публичную/приватную ссылку на задачу.
**Элементы**: заголовок «Share» + ✕; строка автора «A · sc:pacaic1550 · coach»; две карточки-опции «Private — Only you can access» / «Public — Anyone with the link» (выбираются, зелёная галочка на активной); поле ссылки `https://neuratap.com/board/untitled...` + кнопка «Copy» (в других кадрах — «Скопировать» / зелёная «Copied!»); подпись «Share to» + иконки telegram/чат/twitter/facebook/email.
**Состояния**: 4 варианта кадров — базовый tooltip «Share» на иконке, модалка с Private выбран, модалка с Public выбран (+ доп. русские подписи «Приватный»/«Классу» в одном из вариантов — вероятно опция «поделиться с классом»), модалка внутри экрана библиотеки (с паролем, см. выше).

### 3. download (скачать)
**Назначение**: экспорт задачи.
**Элементы** — выпадающее меню из 3 пунктов (точный текст):
- «Скачать PGN»
- «FEN   Скопировать FEN»
- «Скачать изображение»
**Состояния**: tooltip «Download» на иконке → открытое меню из 3 пунктов → toast-уведомление об успехе (зелёная пилюля сверху доски, текст вида «...скачано»/успех) — показано в 2 кадрах с разными положениями доски (в т.ч. кадр с почти зеркальной раскладкой, похоже на демонстрацию скачивания в разных позициях, не смена ориентации доски).

### 4. Add to favorite (избранное)
**Назначение**: пометить задачу как избранную.
**Элементы**: tooltip «Добавить в избранное» на иконке-сердце; toast «Добавлено в избранное» (розовое сердце в пилюле сверху); второй кадр — toast «Удалено из избранного» (переключение обратно, toggle-логика add/remove на одной кнопке).

### 5. timer (таймер)
**Назначение**: ограничение времени на решение пазла.
**Элементы**: tooltip «Таймер»; активный обратный отсчёт в шапке доски («01:20» и т.п., иконка часов); модалка **«Настройка таймера»** (✕ закрыть):
- toggle «Обратный отсчёт» — вкл (фиолетовый)
- «БЫСТРЫЙ ВЫБОР»: кнопки «10 сек», «30 сек» (выбрано), «1 мин», «2 мин», «5 мин»
- toggle «Звуковой сигнал» — вкл
- кнопки «отмена» / «Применить» (белая, акцентная)
**Состояния**: закрыт → бейдж времени идёт → модалка настроек (два кадра модалки — свёрнутый и развёрнутый вид с одинаковым содержимым, судя по всему hover/focus вариации).

### 6. Add to folder (добавить в папку)
**Назначение**: организация задач по папкам.
**Элементы**: tooltip «Add to folder» (англ.); панель «Add to folder» (✕):
- строка «♡ Favorite» (чекбокс)
- секция «Private folders»
- «Untitled» ×2 (чекбоксы, в одном из кадров — с зелёной галочкой = выбрано)
- «+ Create new folder»
Другой кадр той же панели — на русском варианте фигурируют аналогичные пункты «Untitled» с зелёной галочкой выбора (двуязычные копии одной панели в разных кадрах).
**Состояния**: tooltip → открытая панель (ничего не выбрано) → открытая панель (папка выбрана, галочка) → toast «Добавлено в папку» (зелёная пилюля с иконкой чек).

### 7. Flip the board (перевернуть доску)
**Назначение**: сменить ориентацию доски (взгляд за белых/чёрных).
**Элементы**: tooltip «Flip the board» (англ.); во втором кадре иконка активна (подсвечена фиолетовым), бейдж хода меняет цвет/подпись («Ход чёрных»/аналог).
**Состояния**: обычный → нажата/активна (доска переворачивается — фактической разницы в раскладке между кадрами в скриншотах на этом масштабе почти не видно, но кнопка в pressed-состоянии).

### 8. Regenerate (регенерация ИИ)
**Назначение**: сгенерировать новую позицию/пазл через ИИ — ключевая AI-функция продукта.
**Элементы**: tooltip «Regenerate»; **лоадер-оверлей** поверх доски (доска затемнена/desaturated):
- анимированный маскот-персонаж (прыгающий зелёный слайм)
- заголовок «Generating AI tasks...» (англ.)
- зелёный progress-bar (почти заполнен)
- 3 чекпоинта-лейбла под баром: «✓ Fetching patterns», «✓ Calibrating difficulty», «Generating boards» (третий — в процессе, без галочки)
**Состояния**: обычный → генерация в процессе (loading) → (третий кадр) результат — новая позиция с тем же UI.

### 9. Play vs AI (игра против ИИ)
**Назначение**: переключиться из режима «решить пазл» в режим «сыграть партию против бота».
**Элементы**: tooltip «Play vs AI»; второй кадр — другой header доски: бейджи «🔥 played 4d» и «Level 5» (фиолетовый), внизу справа под доской — карточка соперника с аватаром «Александр Ш.»; фигуры на доске уже переставлены (реальная партия, не пазл-позиция) с подсветкой последнего хода.
Отдельно (в связке с секцией Hint) обнаружен кадр именно в контексте «Игра против ИИ» (заголовок «Игра против ИИ» + иконка шестерёнки настроек) — то есть у режима игры против ИИ есть собственные настройки.
**Состояния**: tooltip → активная партия с оппонентом-ботом (уровень сложности показан бейджем «Level 5»).

### 10. Hint (подсказка)
**Назначение**: получить AI-подсказку по решению; ограниченный ресурс, монетизация.
**Элементы**: tooltip «Hint» (англ.); панель «Подсказка» — иконка, короткое описание (2 строки, мелкий текст), кнопка «Показать» (фиолетовая).
**Модалка «Подсказки закончились»** (paywall, критично для бизнес-логики):
- иконка запрета (красный кружок ⊘)
- заголовок «Подсказки закончились»
- подзаголовок «Вы использовали все 3 подсказки для этой задачи»
- заголовок блока «Получить больше подсказок»
- 3 тарифные строки (радио-кнопки):
  - «5 подсказок» — **49**
  - «10 подсказок» [бейдж «выгодно»] — **129** (выбрано по умолчанию, фиолетовая рамка)
  - «♾ Безлимит» — **299**
- кнопка «Купить» (фиолетовая, primary)
- текстовая ссылка «Продолжить без подсказок» (отказаться)
На фоне модалки виден сайдбар с текстом «3 подсказки доступны» (счётчик остатка) и мини-панель «Подсказка» с описанием и кнопкой «Показать».
**Состояния**: обычная подсказка доступна → лимит исчерпан → paywall-модалка выбора пакета.
**Бизнес-правило**: лимит — 3 бесплатные подсказки на задачу; докупка пакетами за внутреннюю валюту «кредиты» (баланс отображается вверху экрана, напр. 670).

### 11. Цвет фона (тема оформления)
**Назначение**: смена цветовой темы всего интерфейса (не только доски).
**Расположение триггера**: НЕ в левой иконной колонке, а рядом с блоком zoom/fullscreen над доской — доп. иконка (сетка/тема, «⊞»), которая появляется только в кадрах этой секции.
**Элементы**: панель «Цвет фона», подзаголовок «Выберите тему», сетка из **9 круглых/квадратных свотчей** в 3 строки × 3 столбца: лаванда/фиолетовый, зелёный, серый — / фиолетовый (насыщенный), красный/коралл, тёмно-серый — / розовый, оранжево-коричневый, бирюзовый/циан.
**Состояния/применение темы** — 2 полноценных кадра-превью применённой темы:
- **Светло-серая тема**: весь фон страницы становится светло-серым/белым (`#F4F7FA`, `#E8EDF9`, `#E6E6E6`, `#B7C0D8`), панели светлые, доска — светлые тона.
- **Розовая тема**: весь фон становится розовым (доска и панели в розовых тонах, акцент — насыщенный розовый/малиновый).
**Важно для фронтенда**: это подтверждает, что дизайн-система должна поддерживать несколько полноценных цветовых тем (минимум 3: тёмная/серая/розовая, плюс ещё варианты по свотчам — итого до 9 тем), а не только «dark mode» как единственный вариант.

## Сводный список бизнес-правил и edge cases

1. Подсказки лимитированы — **3 бесплатные на задачу**; после исчерпания появляется платный paywall с 3 тарифами (5/10/безлимит подсказок за кредиты — 49/129/299).
2. У пользователя единый баланс **«кредитов»** (отображается вверху, напр. «670 кредитов», иконка молнии) — расходуется на подсказки (и, вероятно, на другие premium-функции).
3. Задача (пазл) имеет тип/категорию, отображаемую в заголовке-дропдауне («Мат в 2 хода» — паттерн «Мат в N ходов»).
4. Материальный перевес считается и показывается дважды (над и под доской) в формате «иконки фигур + число».
5. У доски есть индикатор «чей ход» в двух формах одновременно: кнопка-пилюля (англ. «White to move») и radio-переключатель с подписью (рус. «Ход белых») — потенциальная избыточность/несогласованность UI.
6. Папки для сохранения задач делятся на **Private / Public** (аналогично видимости в Share) — есть отдельные секции «Private folders» и «Public folders» в библиотеке.
7. Функция Share поддерживает: приватный/публичный доступ, опциональный пароль для просмотра (обнаружен в варианте «из библиотеки»), прямую ссылку на **neuratop.com**, шаринг в мессенджеры/соцсети (иконки telegram/twitter/facebook/email).
8. Режим «Play vs AI» имеет собственный уровень сложности («Level 5»), отображает историю активности соперника-бота («played 4d») и, предположительно, отдельные настройки (иконка шестерёнки на заголовке «Игра против ИИ»).
9. Таймер поддерживает быстрый выбор длительности (10 сек / 30 сек / 1 мин / 2 мин / 5 мин), toggle обратного отсчёта и toggle звукового сигнала отдельно.
10. Регенерация задачи — асинхронный AI-процесс с многошаговым прогресс-баром (минимум 3 видимых этапа: получение паттернов → калибровка сложности → генерация доски).
11. Список (List) — это обучающий/справочный контент по правилам шахмат (движение фигур, спецходы, мат), организованный иерархически (пункты с вложенными подпунктами), а не журнал истории решений.
12. Тема оформления влияет на весь интерфейс целиком (фон, панели, доску), а не только на цвет клеток — учесть при построении токенов дизайн-системы (минимум light/dark + доп. цветные темы).
13. Обнаружено сильное смешение языков RU/EN в рамках одного и того же экрана и даже одной панели — вероятно недоработанная локализация, требует ревью перед разработкой (список конкретных англицизмов см. в Summary).

## Полный перечень инструментов и функций панели (10 иконок + 1 доп. контрол)

1. **List** — учебные материалы / список правил шахмат (иерархический, с подпунктами).
2. **Download** — экспорт: PGN, FEN (копирование), изображение.
3. **Share** — приватная/публичная ссылка, пароль (в библиотеке), соцсети.
4. **Favorite** — добавить/убрать из избранного (toggle).
5. **Timer** — обратный отсчёт с быстрым выбором длительности и звуком.
6. **Flip the board** — смена ориентации доски.
7. **Regenerate** — AI-регенерация позиции/задачи (с многоэтапным лоадером).
8. **Add to folder** — сохранение в приватную/публичную папку, создание новой папки.
9. **Play vs AI** — игра против бота (уровень сложности, статистика встреч).
10. **Hint** — AI-подсказка, лимит 3/задача, платный докуп при исчерпании.
11. **Цвет фона / тема** (доп. контрол у зума, не в основной колонке) — палитра из 9 тем, полная смена цветовой схемы приложения.

Плюс верхнеуровневая навигация видна в экране библиотеки: **My Puzzles / Progress / My Class / Tournaments** — это, вероятно, глобальная навигация всего продукта (не только тулборда).
